# hammel: Continuous-Time Demographic Microsimulation

Demographic microsimulation in the spirit of SOCSIM but with modern
tools.

## Options

hammel reads the following option, which can be set with
[`options()`](https://rdrr.io/r/base/options.html), or in an
`.Rprofile`:

- `hammel.progress`: the default for the `progress` argument of
  [`run_simulation()`](https://aarongullickson.github.io/hammel/reference/run_simulation.md).
  When unset, a progress bar is shown in interactive sessions and hidden
  otherwise. An explicit `progress` argument takes precedence.
