# Milestone 4 supporting diagnostics

These offline synthetic experiments supplement the accepted report at
[`../milestone4.qmd`](../milestone4.qmd). They were moved here at milestone 4
closeout to keep the report directory uncluttered. Run scripts from the
repository root, not this subdirectory. No results were regenerated by the move.

| Files | Purpose |
| --- | --- |
| `benchmark-calibration-intensity.R`, `calibration-intensity-*.csv` | D082 bookkeeping performance and memory comparison; see [calibration notes](../../design/calibration-intensity.md) |
| `validate-calibration-log-odds.R`, `calibration-log-odds*` | D082 age-based conditional-choice recovery |
| `validate-calibration-log-odds.R`, `duration-remarriage-log-odds*` | D083 duration-based conditional-choice recovery |
| `validate-cohabitation-matching.R`, `cohabitation-matching*` | D086 separate cohabitation/marriage conditional-choice recovery |

CSV files retain replication estimates and summaries. RDS files retain fit or
session/source metadata needed to interpret those estimates. They are not full
simulation histories. Earlier comparisons require their baseline/current
optimized libraries; temporary library paths in the testing record describe the
original runs, not currently installed dependencies. API renames since those
runs may require checking out the recorded source. See
[testing](../../design/testing.md) for commands, findings and limitations.
